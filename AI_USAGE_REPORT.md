# Mandatory AI Usage Report

AI TOOL USED: ChatGPT

## WHAT I ASKED AI TO DO
1. Help translate the assignment business problem into a practical lead-management workflow.
2. Suggest a simple architecture, data model, REST APIs and UI structure for a working prototype.
3. Generate and review boilerplate code, validation logic and test scenarios.

## PROMPT THAT WAS MOST USEFUL
"Design a working admission lead management prototype for an educational institution. It must manage leads from first contact through follow-up and conversion, with counsellor assignment, course preference, lead source, status, follow-up actions, manager visibility, ageing and useful reports/insights. Keep the implementation simple enough to run locally and include important edge cases."

## CODE GENERATED BY AI
Initial backend structure, API boilerplate, frontend component structure, validation helpers and seed data.

## CODE I MODIFIED
I reviewed the generated implementation, connected frontend API calls, adjusted validation, role permissions, ageing rules, dashboard calculations and UI behaviour to match the assignment requirements.

## AI OUTPUT THAT WAS WRONG
Generic generated code can make assumptions about authentication, database behaviour, dates and permissions that do not match the product requirements.

## HOW I IDENTIFIED THE PROBLEM
I ran the application locally, tested API requests, checked validation and tried edge cases such as duplicate phone numbers, overdue follow-ups and role-restricted actions.

## HOW I FIXED IT
I corrected the validation and permission checks, verified the API responses, tested the UI workflows and kept business rules enforced on the server.
